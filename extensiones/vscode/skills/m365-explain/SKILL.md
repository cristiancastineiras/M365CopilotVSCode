Explain what the code I attached does, how it works and anything non-obvious about it (edge cases, pitfalls, performance). Be concise and concrete, and do not rewrite it unless I ask. Read more of the workspace only if the code depends on something you cannot see, and leave the files as they are.

If I attached nothing, the code I mean is the one my message names, or the file open in my editor.
